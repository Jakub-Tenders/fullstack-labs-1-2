# Project proposal

- Name: Jakub MOTYSIA
- Project title: SprayGen
- Pitch (one sentence): A collaborative spray wall bouldering app where climbers create custom boulder problems or randomly generate one by difficulty, and share movement beta.
- Target users: Indoor boulderers and spray wall climbers who want to create custom problems, get random routes at a chosen grade, and exchange beta with other climbers.

## Pages

| URL | Content | Dynamic segment? | Rendering strategy and why |
|---|---|---|---|
| / | Difficulty selector to randomly generate a boulder problem, plus the most recently created problems and beta logs | No | Dynamic server rendering: the problem and beta lists change every time a new route or log is written, so they must be fresh on each request |
| /problems | Full directory of custom and generated boulder problems, filterable by grade and hold style | No | Dynamic server rendering: the filtered list updates immediately as new problems are added |
| /problems/[slug] | One boulder problem: title, grade, hold style, start/crux/finish moves, setter name, community beta logs, and a form to write beta | Yes, `[slug]` | Dynamic server rendering: the problem's moves and climber beta are in the HTML (good for SEO, with the problem title and grade as the page title) and always show the latest logs |
| /problems/new | Form to create and publish a custom boulder problem | No | Client-side rendering: interactive form that sends data to the API/Server Action, no SEO needed |
| /problems/[slug]/edit | Form to edit or delete a boulder problem's sequence and details | Yes, `[slug]` | Client-side rendering: interactive form that loads and updates or deletes the problem, no SEO needed |

## Data

- **Problem**: `id`, `slug`, `title`, `setterName`, `targetGrade`, `holdStyle`, `startHolds`, `cruxSequence`, `finishHold`, `footRule`, `isAutoGenerated`, `createdAt`, `updatedAt`
- **AscentLog**: `id`, `climberName`, `suggestedGrade`, `rating`, `betaNotes`, `createdAt`, `problemId`

Relation: one-to-many. A problem has many ascent logs, and each ascent log belongs to one problem (`AscentLog.problemId` references `Problem.id`).

## Write actions

What users can create, update or delete:

- Create a custom boulder problem (title, grade, hold style, start/crux/finish moves, foot rule, setter name)
- Generate a random boulder problem based on a chosen target difficulty and save it to the database
- Update a boulder problem (edit its title, grade, or move sequence)
- Delete a boulder problem
- Create an ascent/beta log on a problem (climber name, suggested grade, star rating, beta notes)
- Delete an ascent/beta log
